# NeuroScan AI – Brain Tumor Detection System

NeuroScan AI is an AI-powered brain tumor detection web application built using Flask, TensorFlow, and EfficientNetB0.

The system allows users to upload MRI brain scans and receive AI-generated tumor classification predictions along with confidence scores.

## Features

- MRI image upload system.
- Real-time AI prediction.
- EfficientNetB0 deep learning model.
- Flask backend integration.
- Dynamic frontend interface.
- Live MRI preview.
- Confidence score display.

## Technologies Used

- Python.
- Flask.
- TensorFlow / Keras.
- EfficientNetB0.
- HTML.
- CSS.
- JavaScript.
- NumPy.
- Pillow.

## Model Information

- Architecture: EfficientNetB0.
- Transfer Learning: ImageNet pretrained weights.
- Image Size: 240 × 240
- Classes:
  - Glioma
  - Meningioma
  - No Tumor
  - Pituitary
